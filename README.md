# O/L Orbit

A multi-page O/L study companion with a configurable countdown, focus timer, weekly timetable, progress tracker, and study toolkit. Data is saved in this browser with `localStorage`.

Run `python3 -m http.server 8000` from this directory and open `http://localhost:8000`, or open `index.html` directly.

The initial countdown target is **31 December 2026**, a planning placeholder. Set the official exam date from the home page when announced.
